# Hanoi operator district boundaries

`heatsafe_hanoi_operator_districts.geojson` is a deliberately small, offline
subset of the ten districts represented by HeatSafe's synthetic operator
scenario. It is presentation geometry only: it does not supply operational
values, select a plan, or change the authoritative ten-area scope.

Source: [geoBoundaries gbOpen, Viet Nam ADM2, 2020](https://www.geoboundaries.org/api/current/gbOpen/VNM/ADM2/), built 12 December 2023 from OCHA ROAP and the Government of Viet Nam.

License: Creative Commons Attribution 3.0 Intergovernmental Organisations
(CC BY 3.0 IGO). Retain the attribution embedded in the GeoJSON whenever this
asset is redistributed or displayed.

The source includes two districts called `Hoang Mai`; this subset uses the one
whose bounding box contains the HeatSafe `hoang-mai` operator coordinate. The
other lies outside Hanoi and is intentionally excluded.
